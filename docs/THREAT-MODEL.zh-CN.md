# 威胁模型

[English](THREAT-MODEL.md) | [简体中文](THREAT-MODEL.zh-CN.md)

## 受保护资产

- DSH 与 DeepSeek 凭据。
- npm 全局 DSH 安装及下载前置组件、插件的完整性。
- 无关本地应用及其端口、进程的可用性。
- 当前用户的本地文件和浏览器会话。

## 信任边界

启动器信任自身已签名文件、操作系统和明确列入允许清单的上游服务。npm 包、GitHub 压缩包、浏览器内容、日志文本、环境变量和现有本地进程均视为不可信输入。

## 必需控制

- 服务器只能绑定 IPv4 回环地址 `127.0.0.1`。
- 路径和参数不得经过 Shell 插值。
- 每次操作只解析一次 npm 全局根目录，启动或终止进程前验证 DSH 包名和清单。
- 只终止可验证为全局 DSH 的已记录进程树，绝不终止全部 `node.exe`。
- 可变状态保存在仅当前用户、SYSTEM 和管理员可访问的目录。
- 写日志前脱敏 URL 凭据、令牌、授权标头和疑似机密查询参数。
- 崩溃恢复地址以当前用户范围的 Windows DPAPI 加密；恢复前重新验证 PID、安装路径、命令行和端口。
- 使用命名互斥锁及仅限同一用户的命名管道实现单实例。
- 下载使用 HTTPS 允许清单、固定版本和 SHA-256 校验。
- 依赖清单与状态插件嵌入应用文件，不从可执行文件旁加载可修改副本。
- 任务状态失败或过期时保守地维持服务器，不中断未知任务。
- 不静默提权；请求 UAC 前解释系统级前置组件变更。

## 范围外

启动器无法保证上游 DSH 任务、用户安装的插件、npm 注册表、GitHub、Node.js 或浏览器本身的安全。Windows 当前用户或管理员账号已经失陷也不在本项目防护边界内。
