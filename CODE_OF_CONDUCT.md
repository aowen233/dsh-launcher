# Code of conduct

[English](CODE_OF_CONDUCT.md) | [简体中文](CODE_OF_CONDUCT.zh-CN.md)

Be respectful, constructive, and specific. Harassment, threats, discrimination,
publishing private information, and intentionally unsafe contributions are not
acceptable.

Maintainers may edit or remove abusive content and temporarily or permanently
restrict participation. Security reports must follow `SECURITY.md` rather than
being used to publicly expose users.

Report conduct concerns privately to the repository owner once the public
contact address is configured.
