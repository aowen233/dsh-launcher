# Support

[English](SUPPORT.md) | [简体中文](SUPPORT.zh-CN.md)

- Bugs and feature requests: use GitHub Issues.
- Security vulnerabilities: use private vulnerability reporting as described
  in `SECURITY.md`.
- DeepSeek Harness behavior: consult the upstream DSH project first.
- Whale Widget behavior: consult the MeteorNOX upstream project first.

Attach redacted logs only. Never post API keys, access tokens, cookies, or full
environment dumps.
